#TwitterClone

A modern Twitter-like Android application built using Jetpack Compose and Firebase.

Features:
- User login with username
- Post tweets in real-time
- Comment system for each tweet
- Like functionality
- Delete tweets and comments (with permissions)
- Smart sorting (latest, most liked, A–Z, Z–A)
- Search functionality
- Smooth animations and splash screen
- Clean UI with custom theming (white + orange)

Tech Stack:
- Kotlin
- Jetpack Compose
- Firebase Firestore
- Material 3

This project focuses on building a responsive UI, real-time data handling, and smooth user experience.
